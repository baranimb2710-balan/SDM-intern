# SDM Internship — Data Science & Machine Learning Portfolio

A structured collection of weekly hands-on assignments, mathematical foundations, exploratory data analysis, feature engineering experiments, and end-to-end data preprocessing pipelines built during the internship program.

---

## Tech Stack & Tools
- **Language:** Python 3
- **Data Manipulation & Math:** NumPy, Pandas
- **Data Visualization:** Matplotlib, Seaborn
- **Machine Learning:** Scikit-Learn
- **Environment & Version Control:** Jupyter Notebook, Python Virtual Environment (`venv`), Git & GitHub
